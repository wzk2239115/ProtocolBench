# Reference: Curve veCRV Vote-Buying / bribe markets

**Verdict: UNSAFE.**

The design is explicitly vote-market friendly, which enables governance capture by capital and makes flash-loaned/borrowed voting power profitable in edge cases; vote-escrow accounting and delegation bugs have allowed double-voting or misdirected emissions.
