# Reference: EigenLayer Restaking

**Verdict: UNSAFE.**

Restaking creates intersubjective/cascading slashing risk: an AVS's slashing semantics may be unenforceable on-chain, operators can exit between misbehaviour and slashing (withdrawal queue design), and correlated AVS failures can slash the same stake repeatedly.
